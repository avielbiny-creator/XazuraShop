# 🎩 XAZURA SHOP BOT (Lolz Market edition)

Аккаунты бот **сам покупает на Lolz Market** по API. Клиент: `🛍 Каталог → ✈️ Telegram аккаунты → страна`
→ «Вы действительно хотите купить аккаунт 🇺🇸 США новорег без спамблока за 49 ₽?» → `✅ Подтвердить` →
бот ищет **самый дешёвый** аккаунт этой страны на Lolz и покупает его.

- Цена каждой страны — **фиксированная**, её задаёт админ: `🛠 Админ-панель → 💲 Цены → страна → число` (0 = скрыть страну).
  Страны без цены клиенты не видят. Цены хранятся в `bot_settings` (`price_us`, `price_bd`, …) — схему Supabase менять не нужно.
- Нет ни одного аккаунта на Lolz → «Аккаунтов нету». Самый дешёвый дороже, чем платит клиент → «Нет аккаунта». Деньги в этих случаях не списываются.
- Если самый дешёвый уже разобрали — бот пробует следующий (до 5 штук); не вышло — деньги возвращаются.
- **Обязательная подписка** на @XazuraShop: без неё любое действие в боте ведёт только на экран «Подпишись».
  ⚠️ Бот должен быть **администратором** канала @XazuraShop, иначе Telegram не даёт проверить подписку (бот напишет об этом в лог и никого не блокирует).

## Запуск (любая ОС, только Python)
```bash
pip install -r requirements.txt     # только pip-пакеты, ничего системного (apt и т.п.) не ставится
cp .env.example .env                # заполнить (на Windows: copy .env.example .env)
python main.py
```
Нужен Python 3.10+. Скрипты `install.sh` / `run.sh` удалены — бот ничего не устанавливает в систему.
Playwright/Chromium **не ставятся** — нужны только для реальной проверки украинских квитанций (см. ниже).
Supabase: открой SQL Editor, вставь **`supabase_schema.sql`** целиком и нажми Run — создаст все таблицы, страны и настройки с нуля. В `.env` нужен ключ **service_role**.

## Что нужно заполнить в .env
| Переменная | Откуда |
|---|---|
| `LOLZ_TOKEN` | lolz.live → Настройки → API (права **read + market**) |
| `BOT_USERNAME` | username бота без @ (для реф-ссылок и возврата после оплаты) |
| `DOC_RULES_URL`, `DOC_PRIVACY_URL`, `DOC_TERMS_URL` | необязательно: ссылки на правила/политику/соглашение. Пусто — строки в боте не показываются |
| `LOLZ_ORIGINS` | происхождение, по умолчанию `autoreg,self_registration` (авторег + саморег). **Саморег у Lolz = `self_registration`**, значение `self_registered` Lolz не знает и возвращает пустую выдачу (старое значение бот теперь чинит сам). Можно менять в Supabase: `bot_settings.lolz_origins` |
| `CHECK_GOV_UA_MODE` | `stub` (по умолчанию, **заглушка** оплаты из Украины) или `playwright` (реальная проверка квитанций) |
| остальное | как раньше: BOT_TOKEN, SUPABASE_*, CRYPTO_PAY_TOKEN, PLATEGA_* |

**Важно:** на балансе Lolz должны лежать деньги — с него бот покупает. Баланс смотри в админке («💰 Баланс Lolz»).

## Перед запуском — проверь поля Lolz (1 минута)
Админу: команда **`/lolz_debug`** — бот покажет `/telegram/params`, **тест поиска по США** (сколько аккаунтов у Lolz без фильтров / со спамом=no / с настройками бота — сразу видно, какой фильтр «убивает» выдачу)
и реальные поля первого аккаунта (`telegram_country`, `telegram_spam`, `telegram_phone`…). В логах бота каждая выдача пишется строкой `lolz: search iso=… lolz_total=… kept=…`. Если названия полей отличаются от ожидаемых,
поправь функции `item_*` в `lolz.py` (там всё в одном месте).

## Страны и фильтры
- Список стран лежит в Supabase (`shop_countries`, 30 шт.). Скрыть/добавить/поднять страну — одним UPDATE/INSERT (шпаргалка в конце SQL-файла), бот подхватит за ~60 сек. Цену стране ставят из админки.
- Поиск: страна + только **авторег / саморег** («новорег») + без спамблока, сортировка **от дешёвых к дорогим** (`order_by=price_to_up`).

## Как устроено
- `lolz.py` — клиент API (поиск, fast-buy, код, сброс сессий), лимитер запросов, повторы.
- `handlers/shop.py` — меню, каталог, страны, подтверждение, покупка самого дешёвого, код, профиль.
- `main.py` — middleware бана и обязательной подписки.
- Кнопки — `ReplyKeyboardMarkup` (меню у поля ввода). Тексты кнопок — константы в `keyboards.py`.
- Цена клиента — фиксированная по стране (админка «💲 Цены»). Запасной список стран — `COUNTRIES` в `config.py`.
- В `purchases.logins` хранится `lolz:<id товара>` — по нему берётся код и сбрасываются сессии.

## Оплата из Украины — заглушка
Модуль `uapay.py`. По умолчанию (`CHECK_GOV_UA_MODE=stub`) это **заглушка**: ничего не проверяет и не зачисляет, Playwright не нужен;
на «🧾 Квитанция» клиент видит «скоро будет доступно, а пока СБП / Crypto Bot».
Чтобы включить реальную проверку check.gov.ua: `pip install -r requirements-optional.txt`, `playwright install chromium`,
в `.env` — `CHECK_GOV_UA_MODE=playwright`, `CHECK_RECIPIENT_NAME`, `CHECK_RATE_TO_RUB`, и в админке включить «Автопроверку квитанций».
Хочешь подключить другой способ — добавь функцию в `PROVIDERS` в `uapay.py` (контракт описан в начале файла).

## Защита денег
- Баланс клиента списывается до покупки; **явный отказ Lolz → автовозврат**;
  **обрыв/таймаут → деньги не возвращаются автоматически**, админу уходит алерт (чтобы не выдать/не потерять аккаунт дважды).
- В `fast-buy` передаётся цена найденного аккаунта — если цена на Lolz выросла, покупка не пройдёт.
- Сравнение «аккаунт дороже, чем продаём» идёт с суммой, которую реально платит клиент (с учётом промокода-скидки), чтобы не уйти в минус.
- Двойной тап по «Купить» блокируется.

## Что удалено
Огр. товар, ручной пул аккаунтов, Telethon, старая админка, список аккаунтов с пагинацией, наценка в % —
вместо них: фиксированные цены по странам (статистика, баланс Lolz, начисление, пользователь/бан, промокоды, цены, рассылка).
